# Lakita Ingole — Personal Portfolio

Personal portfolio website for **Lakita Rajendra Ingole**, a second-year B.Tech Computer Science and Engineering student aspiring to become an AI/ML Engineer and Web Developer.

🌐 **Live website:** 
[Open the deployed portfolio](https://lakita-portfolio-e3p5gfslx-lakitaingole82-webs-projects.vercel.app)

## About

The site presents Lakita’s academic journey, developing technical skills, projects, leadership experience, certifications, and contact information. It features a scroll-linked hero animation, a responsive layout, and a downloadable resume.

## Features

- Responsive layout for desktop and mobile
- Scroll-linked hero animation
- About section and professional objective
- Projects: Krushi-Setu, Skill Verse, and Personal Portfolio Website
- Technical skills and tools
- Leadership and education timelines
- Certifications and technical activities
- Contact links and downloadable resume PDF

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run Locally

### Requirements

- Node.js
- pnpm
